# Skills 使用指南

> 知识库模板的 Agent 技能使用方式、触发条件和知识贡献规范。

---

## 一、可用命令

### 斜杠命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `/新知识 <主题>` | 按规范创建新文档 | `/新知识 Git常用命令` |
| `/周复盘` | 生成本周运营周报 | `/周复盘` |
| `/查链接` | 检查并修复断链 | `/查链接` |

### 维护脚本

```bash
python scripts/knowledge_index_generator.py   # 重建索引 + 生成 AI_MANIFEST.md
python scripts/knowledge_link_checker.py      # 检查所有 Wiki 链接有效性
```

## 二、知识贡献规范

### 添加新知识条目

**文件命名**：`YYYY-MM-DD-简短描述.md` 或 `分类-主题.md`

**必需 frontmatter**：
```yaml
---
topic: [主题分类]
date: YYYY-MM-DD
status: [已整理 / 已验证 / 待验证 / 草稿]
tags:
  - [标签1]
  - [标签2]
---
```

**必需章节**：
- 正文：结构化内容
- `## 关联`：至少 2 条 `[[wiki链接]]`，其中至少 1 条指向 MOC 枢纽

**提交前检查**：
- [ ] 所有链接指向的页面存在
- [ ] 已连接到对应 MOC 枢纽
- [ ] 标签与内容匹配

### 目录分类规范

| 目录 | 放什么 | 不放什么 |
|------|--------|---------|
| `知识库/` | 技术参考、产品方案、市场研究、竞品分析 | 零散的日报 |
| `运营思路/` | SOP、方法论、运营指南、复盘模板 | 纯技术文档 |

### MOC 维护规则

1. 新增内容后 → 同步更新对应 MOC 枢纽页的链接列表
2. MOC 之间交叉引用（每个 MOC 底部有相邻枢纽导航）
3. MOC-工作流全景 连接各领域 MOC

## 三、典型使用场景

### 场景 1：新增技术笔记

```
用户：/新知识 Docker部署踩坑
Agent：
  1. 读取本规范 → 创建 Knowledge/知识库/YYYY-MM-DD-Docker部署踩坑.md
  2. 填入 frontmatter（topic: 技术参考, tags: [技术, 踩坑]）
  3. 写入正文模板（环境 → 步骤 → 踩坑 → 关联）
  4. 运行 knowledge_index_generator.py 更新索引
```

### 场景 2：每周复盘

```
用户：/周复盘
Agent：
  1. 扫描 Knowledge/ 下本周新增/修改的文件
  2. 按 运营思路/示例-运营复盘.md 模板生成周报
  3. 保存到 运营思路/YYYY-MM-DD-本周复盘.md
```

### 场景 3：健康检查

```
用户：/查链接
Agent：
  1. 运行 python scripts/knowledge_link_checker.py
  2. 列出所有断链及其位置
  3. 询问用户是否逐个修复
```
